# What a Great Drag-and-Drop Editor Should Actually Do

I think the best drag n drop email creation app would only be able to be built by someone that generally dislikes drag n drop email editors.

Before any AI sparkly unicorn features are ever introduced, I think some important aspects that would be mandatory would be:

- Ability to provide custom code that ties into the UI's capabilities with proper documentation.
- Less opinionated on email client compatibility, with no behind-the-scenes decisions on which email clients will be prioritized.
- Usable by non-technical people while still enhanceable by email developers.
- Supports DRY (don't repeat yourself) principles, allowing quick jump-starts for clients with a library of custom branded modules that are fully tested in a short time.
- Supports an ecosystem of technical partners, who then support end-users, providing better employment opportunities and optional dedicated support to end-users.

Everything listed above actually already exists, it just needs fine-tuning and modern enhancements to improve performance.
